# Webhook

A webhook is used to POST new, updated, or deleted records to your server.

## Example Usage

```typescript
import { Webhook } from "@unified-api/typescript-sdk/sdk/models/shared";

let value: Webhook = {
  connectionId: "<id>",
  event: "deleted",
  objectType: "repo_pullrequest",
};
```
